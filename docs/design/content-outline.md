# MatchStats 页面信息架构与内容大纲 (Content Outline)

## 一、主屏信息架构 (Main Screen Layout)

### 1. 侧边导航栏 (Sidebar / Navigation)
- **目的**：明确工作台品牌身份与主数据源切入点。
- **元素**：
  - 品牌标识：`MatchStats`（足球矢量徽标 + 终端极简字标）
  - 数据源切换项：
    - `欧洲赛事数据 (Football-Data)` [核心活跃 Tab]
    - `中国竞彩数据` [技术代码保留，前端样式隐藏]
  - 底部系统态势：
    - 数据库心跳（正常/异常状态圆点）
    - 真实最后同步时间戳

### 2. 顶部综合控制台 (Header Console & HUD)
- **目的**：多维状态瞬时把控与全局过滤控制，首屏 5 秒内明晰全局规模与操作入口。
- **元素**：
  - 页面主标：`欧洲主流联赛赛事量化数据中心`
  - HUD 指标条：
    - 欧洲赛事总库存（例如：`1941 场`）
    - 当前过滤视图（例如：`100 场`）
    - 数据库运行健康度（`活跃` / `连接正常`）
  - 全局操作区：
    - `刷新数据` 按钮（带实时轮转动画）
    - 比赛状态过滤器：`全部` / `进行中` / `未开始` / `已结束`

### 3. 主工作区左栏：赛事日程与胜率量化流 (Matches & Opta Stream)
- **目的**：赛事量化分析核心，单场多维数据即时对比。
- **元素**：
  - 联赛水平切换轨：`全部` / `英超` / `西甲` / `德甲` / `意甲` / `法甲` / `欧冠`
  - 比赛行级条目（Match Row）：
    - 开赛时间（等宽 HH:mm + MM/DD）
    - 主队徽章与中文全名
    - 核心比分牌（实时比分或 VS，等宽高对比度渲染）
    - 客队中文全名与徽章
    - 比赛状态徽章（`完场` / `进行中(LIVE)` / `未开赛`）
    - **Opta AI 胜率全景微条**：主胜/平/客胜百分比 + 三色贯穿比例条

### 4. 主工作区右栏：量化榜单与日志 (Standings, Scorers & Logs)
- **目的**：提供联赛宏观格局支撑与系统级数据审计。
- **元素**：
  - 榜单 Tab 组：`积分榜` / `射手榜` / `助攻榜`
  - 积分榜表格：排名、球队、场次、积分、净胜球、欧冠/降级区微色标
  - 射手/助攻榜表格：排名、球员姓名、效力球队、进球数与助攻数
  - 系统底层同步日志监控流：时间、任务类型、同步状态

## 二、比赛详情弹窗架构 (Match Details Modal)

### 1. 顶部对决仪表盘 (Match Header Scoreboard)
- 比赛时间、主客队名称、大字号等宽比分、裁判信息、开赛状态。

### 2. Opta AI 胜率深度解析模块 (Opta AI Intelligence Card)
- 主胜 / 平局 / 客胜横向多轨对比罗盘。
- 预测置信度与模型综合陈述文本。

### 3. 双方首发阵容与战术站位 (Lineup & Tactical Formation)
- 主队首发名单与主教练、替补名单。
- 客队首发名单与主教练、替补名单。
- 球员号码、中文译名、场上位置（门将/后卫/中场/前锋）。

### 4. 实时进球事件时间轴 (Match Goals Timeline)
- 进球分钟数、球员姓名、进球类型（常规/点球/乌龙）。

### 5. API 原始底层数据折叠器 (Raw Data Inspector)
- 展开/收起完整后端 JSON，方便开发者与量化分析师审查原始字段。
