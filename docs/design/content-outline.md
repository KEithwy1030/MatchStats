# MatchStats 内容大纲与信息架构 (Content Outline & IA)

## 1. 核心定位与顿悟时刻 (Aha Moment)
- **顿悟时刻 (5秒内传达)**：一眼看清当前欧洲各大联赛焦点战况、即时比分与 Opta 权威胜率投影。
- **唯一主动作**：快速切换联赛与赛况状态，查看单场深度详情及 Opta 胜率走向。

---

## 2. 页面区块规划与流线 (Block Sequence & Objectives)

### 区块 1：品牌导航栏与全局控制顶栏 (Top Navigation & Command Bar)
- **目的**：确立 MatchStats 品牌身份，提供快速刷新、全局联赛快速切换、实时赛况状态过滤器。
- **元素**：
  * 品牌徽标：MatchStats 旗舰标示 + “Opta AI 胜率分析中心” 专业副标；
  * 核心赛况状态切换：全部 (All) / 进行中 (Live) / 未开赛 (Upcoming) / 已完赛 (Results)；
  * 联赛快速导航横条（英超 PL、西甲 PD、德甲 BL1、意甲 SA、法甲 FL1、欧冠 CL）；
  * 辅助信息：数据源更新时间、手动刷新触点。
- **废弃鸡肋元素**：移除空洞无用的 240px 纵向死侧边栏，将视线焦点完全还给球赛数据本身。

### 区块 2：微型关键概览条 (Compact Intel Ribbon)
- **目的**：替代原版 3 个巨大且笨重的 Stat Cards，压缩为顶部紧凑、精致的单行信息条（包含今日焦点赛事统计、Opta 胜率预测覆盖度、API 实时通畅状态），纵向高度不超过 40px，释放 120px+ 首屏高度给赛程。

### 区块 3：赛事焦点列表 (Matches Grid / Fixture Feed - 核心主体)
- **目的**：展示当前筛选条件下的全部赛事，提供极致清晰的对阵、比分、状态与 Opta AI 胜率图谱。
- **卡片要素**：
  * **赛事时间与轮次**：开球时间、比赛日期、所属联赛徽标；
  * **交手双方**：主队与客队名称（高辨识度排版，字重清晰，胜者/领先者视觉明确）；
  * **比分与状态**：
    * 进行中：动态呼吸红绿状态标记 + 即时比分；
    * 已完赛：清晰最终比分；
    * 未开赛：对决标识与开赛倒计时/开球时间；
  * **Opta AI 胜率核心投影条 (The Signature Opta Gauge)**：
    * 三段式精确比例条（主胜 / 平局 / 客胜）；
    * 突出显示最高概率项，配以专业百分比数值与权威 Opta 图标。
  * **交互触点**：点击整卡唤起比赛详情浮层。

### 区块 4：右侧辅助专业面板 (Side Intelligence Column)
- **目的**：为数据分析师和硬核球迷提供纵深赛事背景。
- **子面板 1：积分榜 (Standings)**：当前联赛排名、球队、场次、胜平负、净胜球、积分，欧冠区/降级区细微色彩区分。
- **子面板 2：射手榜 / 助攻榜 (Top Scorers & Playmakers)**：球员、球队、进球数与点球数/助攻数，Tab 快速切换。
- **子面板 3：底层数据同步日志 (Sync Diagnostics)**：极简折叠式状态指示器，保障系统透明度。

### 区块 5：比赛深度详情模态弹窗 (Match Detail Modal)
- **目的**：点击比赛后展现阵容、进球事件与 Opta 深度预测。
- **元素**：双方首发 11 人阵型及替补名单、进球事件时间轴（进球者、助攻者、进球类型）、Opta AI 胜率深度拆解。

## 3. 状态设计 (Application States)

1. **加载状态 (Loading State)**：
   - 使用与设计语言基调一致的优雅脉冲占位骨架屏（Skeleton Loader），严禁生硬转圈或整屏白屏。
2. **空状态 (Empty State)**：
   - 当筛选“进行中”但无即时赛事时，提示：“当前联赛无正在进行的比赛”，并提供“查看今日完整赛程”一键切换按钮。
3. **网络/接口降级状态 (Degraded / Fallback State)**：
   - 自动无缝激活 `CLIENT_BASELINE_MATCHES` 基线数据，顶部浮出极轻微琥珀色提示：“当前展示离线高可用缓存”，保证用户随时可用。
4. **异常错误状态 (Error State)**：
   - 接口超时或 500 时，提供清晰“重试连接”按钮，并展示最近一次成功同步时间。

## 4. 移动端 (Mobile 390x844) 专属布局设计

- **头部优化**：顶栏紧凑排布，品牌在左，刷新与赛况 Filter 采用滑块/胶囊式水平滚动。
- **联赛横向滑动栏 (Sticky League Chips)**：单行横向水平滑动手势切换联赛，随滚动微吸顶。
- **移除堆叠大卡片**：彻底消除 3 个竖排大卡片，首屏 100% 呈现即时比赛。
- **卡片纵向流**：每场比赛卡片单手舒适点击（Min Height 88px），比分居中醒目，Opta 概率条在移动端宽度全铺，数字清晰不重叠。
- **分屏 Tab 机制**：移动端底部或子 Tab 切换“赛事日程”与“积分榜/射手榜”，不再无脑纵向无限下推导致右侧内容不可见。
