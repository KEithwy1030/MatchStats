# MatchStats 设计语言规范 (Design Language Specification)

## 1. 现状诊断与旧设计处置 (Baseline Diagnosis & Treatment)

### 现状诊断 (基于 Baseline 截屏反思)
- **真问题一：头部 3 个巨大 KPI 卡片极度浪费首屏黄金视野**
  原版顶部堆叠 "1941 欧洲赛事总库存"、"11 当前视图场次"、"活跃 数据库状态"，桌面端占用了近 180px 垂直高度，移动端更是 3 个竖排大白框占满整个首屏，把真正重要的比赛列表挤出了第一屏。
- **真问题二：左侧 240px 纵向死侧边栏极其鸡肋**
  竞彩数据隐藏后，左侧栏只剩下唯一的“欧洲赛事数据”按钮，占据桌面端 15% 宽度，造成大面积无效留白。
- **真问题三：比赛列表缺乏足球数据专业质感**
  队名与比分排版平淡散漫，比分仅仅是一个浅灰小框，队标缺失，主客对决张力不足。
- **真问题四：Opta AI 胜率被严重边缘化**
  仅作为一个靠右微缩的次要小药丸，没有融入比赛卡片的核心视觉主轴，未体现“Opta AI 胜率分析中心”的旗舰价值。
- **真问题五：移动端排版严重错乱**
  "比赛日程表" 标题被挤压竖向折行成双列，Tab 栏与卡片横向溢出，积分榜被推到几屏之后无法快捷查看。

### 旧设计处置决策
- **KPI 大卡片**：【放弃】。改用高度仅 36px-40px 的紧凑情报条或微型工作台仪表。
- **左侧死导航栏**：【放弃】。升级为顶部现代化全宽 Masthead 导航，集成品牌、赛况 Filter 与全局操作，横向空间全量释放给球赛。
- **比赛卡片与 Opta 胜率**：【重做】。构建专属“主客对阵舞台 + 核心比分舱 + 旗舰 Opta 胜率图谱”三位一体卡片。
- **竞彩隐藏逻辑与 API 契约**：【严格沿用】。保持 100% 稳定兼容。

## 2. 品牌气质与取舍 (Temperament & Trade-offs)

> **核心气质一句话**：
> **严谨深邃但不死板压抑，专业高密但不杂乱窒息。**

### 两组核心取舍：
1. **权威智库与大众可读的取舍**：追求 Opta Analyst / The Athletic 顶级足球媒体的权威出版感，但拒绝假装高深的小字号和晦涩暗码，队名、比分、胜率百分比必须一眼扫清。
2. **高信息密度与呼吸留白的取舍**：在单卡内集成联赛、对决、比分、首发状态、Opta 胜率三段比，但通过严密的微网格与阶梯对比度分离层级，避免无界面的视觉疲劳。

## 3. 双方向视觉对照决策 (Step 20 Calibration)

### 方向 A：旗舰体育数据智库风 (Flagship Editorial / Opta Analyst Style)
- **视觉心智**：深邃高级、英伦出版物风骨、威严克制。
- **色彩设计**：
  * 画布底色：`#09100d`（球场午夜深墨绿黑）
  * 卡片底色：`#101a15`，浮层 `#15241d`
  * 核心强调色：`#d4a34b`（Opta 权威皇家金，仅在胜率标签与关键品牌处点睛）
  * 赛事实时色：`#1f9457`（草坪深绿）、`#e04545`（焦点红）
  * 文字层级：标题 `#f7f6f2`（象牙米白）、正文 `#d2dbd5`、次级 `#85968d`
- **招牌决定 1**：【三元图谱 Opta 概率带】在每张焦点比赛卡片底部无缝延展，带有主胜/平局/客胜高辨识度色块与“切尔西 46.5% 主胜领先”自然优势标牌。
- **招牌决定 2**：【英伦报刊式 Masthead】品牌 Crest 盾徽 + 次级联赛横向滑轨，营造高级专业刊物感。

### 方向 B：现代化高密度赛事工作台 (Modern High-Density Match Station)
- **视觉心智**：现代敏捷、高密度决策、科技呼吸感。
- **色彩设计**：
  * 画布底色：`#0b1212`（哑光深碳青）
  * 卡片底色：`#111a19`，悬浮 `#152220`
  * 核心强调色：`#10b981`（电光薄荷绿）、`#f43f5e`（玫瑰客胜红）
  * 文字层级：标题 `#ffffff`、正文 `#f1f5f4`、次级 `#94a7a3`
- **招牌决定 1**：【精密罗盘工作台卡片】内置比分黑匣舱、胜率动量趋势指示（`▲ 46.5% 切尔西占优`）。
- **招牌决定 2**：【顶部微型仪表行】28ms 延迟、在库赛事、Opta 覆盖度紧凑矩阵，空间极致压缩。

## 4. 用户视觉反应与定版决策 (User Visual Reaction & Final Decision)
- **校准时间**：2026-11-04
- **用户原话反馈**：用户已经完成【视觉校准门】决策，明确选定：**【方向 A：旗舰体育数据智库风】（深邃墨绿黑 + 象牙白金，Opta 全景三元胜率带，英伦专业体育媒体质感）**。
- **实施依据与冻结规则**：
  1. 页面主色调确定为深邃球场暗墨绿黑 (`#09100d`)，卡片统一使用 `#101a15`，悬浮层 `#15241d`。
  2. 核心品牌视觉锚点：Opta 皇家金 (`#d4a34b`) 与象牙米白 (`#f7f6f2`)，字重克制稳健。
  3. 招牌设计 1【全景三元胜率带】在正式看板比赛列表与详情弹窗中全量落实，支持“主胜/平局/客胜”精确宽度渲染与“某队 xx% 优势占优”智能标牌。
  4. 招牌设计 2【权威报刊式 Masthead + 次级联赛横向滑轨】替代原版空洞的 240px 侧边栏，将全部水平与垂直首屏空间全额释放给赛事列表。

## 5. 禁区 (Strict Prohibitions)

1. 严禁使用深蓝黑底 (`#0f172a`) + 荧光青紫 (`#06b6d4` / `#a855f7`) 的廉价赛博 AI 套板。
2. 严禁堆砌无意义的英文量化全大写标签（如 `QUANT PRO`, `ENTRIES`, `PIPELINE ACTIVE`）。
3. 严禁正文字体小于 11px 或大面积使用单薄等宽字体，保证队名与状态对各类视力完全友好。
4. 严禁前端显示中国竞彩数据，保留代码并隐藏。
