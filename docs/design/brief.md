# MatchStats 设计简报 (Design Brief)

## 1. 项目基础事实 (Facts)

### ① 用户确认的事实 (User-Confirmed Facts)
- **项目定位**：MatchStats 是欧洲主流足球赛事数据与 Opta AI 胜率分析中心。[来源: 用户指令]
- **核心受众**：专业球迷、赛事数据分析师、关注比赛走势与 Opta 官方概率的专业受众。[来源: 用户指令]
- **覆盖联赛**：英超 (PL)、西甲 (PD)、德甲 (BL1)、意甲 (SA)、法甲 (FL1)、欧冠 (CL)。[来源: 代码 `app/config.py` 与线上数据]
- **核心数据资产**：
  * 实时赛事比分与赛程（进行中 LIVE、未开赛 SCHEDULED、已完赛 FINISHED）。[来源: 代码及 API]
  * Opta AI 官方胜率模型预测数据（主胜概率、平局概率、客胜概率）。[来源: VPS 接口返回数据]
  * 联赛积分榜（排名、胜平负、积分、净胜球）。[来源: API 契约]
  * 联赛射手榜与助攻榜。[来源: API 契约]
  * 单场比赛详情（首发阵容、替补、进球事件时间轴）。[来源: API 契约]
- **操作环境与承载**：支持桌面宽屏 (1920x1080) 与移动设备 (390x844)，在 Vercel 静态托管与 VPS 动态 API 聚合下运行。[来源: 代码 `vercel.json`]

### ② 营销主张与待核实清单 (Marketing Claims & Unverified)
- 本产品定位为纯粹严谨的专业体育数据终端，**无任何虚构的营销主张**（如“胜率超 90%”、“AI 必中推荐”等一律禁止出现）。
- 对外文案必须使用客观的中性术语（如“Opta AI 胜率投影”、“赛前战力概率”、“赛事数据中心”）。

### ③ 内部技术细节 (Internal Tech Details - 默认不对外展示)
- VPS 节点 IP (`162.35.175.153:8792`) 与本地代理端口；
- SQLite 数据库内部路径、定时同步 cron 调度策略；
- 内部 API Key 鉴权中间件参数。

## 2. 核心红线 (Red Lines)

1. **红线一【用户原话】**：中国竞彩数据必须在前端隐藏（`display: none !important;`），保留原有处理逻辑与数据兼容代码，严禁在前端主动渲染中国竞彩入口。
2. **红线二【用户原话】**：后端已有 API 契约（Football-Data 适配层、比赛详情、积分榜、射手榜、助攻榜）严禁破坏，字段映射保持 100% 兼容。
3. **红线三【用户原话】**：Opta AI 胜率必须在列表中具备极佳的层级与视觉融合，成为视觉核心价值点之一。
4. **红线四【用户原话 / Skill 规则】**：绝不使用 AI 默认模板（无脑纯黑底、荧光青紫、无脑等宽小字、假装量化终端的英文大写标签如 QUANT PRO、ENTRIES、Tailwind 默认色值）。
5. **红线五【GEMINI 记忆库】**：杜绝推测与乱码。使用 UTF-8 编码，端到端截图闭环验证无溢出、无乱码。

## 3. 反默认自检 (Anti-Default Inspection)

- **该品类最常见的 AI 默认外观**：
  * 深黑灰暗沉底色（如 `#090d16`）、冷青色 (`#06b6d4`) 与洋红色 (`#f43f5e`) 荧光撞色；
  * 全局微缩 JetBrains Mono 字体，生硬堆砌无意义的英文全大写标签（“STATUS: ACTIVE”, “PIPELINE HEALTH”）；
  * 队名、比分排版压抑且无法一眼看清，失去顶级体育数据媒体的人文质感。
- **本方案的根本区别**：
  * 摆脱“伪黑客/伪量化暗黑终端”的刻板印象，立足于顶级欧洲体育媒体（如 Opta Analyst、The Athletic、FotMob）的尊贵典雅与清晰可读；
  * 强化比分对比、队徽辨识、赛程状态的醒目感；
  * Opta 胜率条采用更符合足球美学的深邃比例图谱，兼顾专业分析深度与大众可读性。
