# MatchStats 前端视觉重构设计简报 (Brief)

## 1. 项目基础事实（事实分级）

### ① 用户与业务确认的事实 (Confirmed Facts)
- **定位**：MatchStats 是欧洲五大联赛及欧冠的专业足球数据中台与量化分析工作台。
- **目标用户**：资深赛事量化分析师、数据驱动型球迷与专业机构使用者，重视数据即时性、数字排版严密性、比分与赔率/胜率对比清晰度。
- **核心数据资产**：
  - 欧洲赛事日程（状态、比分、主客队、裁判、开赛时间）。
  - Opta AI 赛事胜率三轨模型（主胜 / 平局 / 客胜概率及动态置信度投影）。
  - 联赛积分榜（排名、胜平负、净胜球、积分）。
  - 射手榜与助攻榜（进球/点球/出场、助攻/进球联动）。
  - 比赛首发阵容与战术站位（球员号码、位置、阵型 place、主客队教练）。
  - 实时系统同步日志与数据库活跃度。

### ② 营销与主观声明 (Marketing Claims / Scope)
- 打造具有 "Opta Analyst / Bloomberg Terminal 级别" 的专业高质感赛事分析工作台。
- 追求高信息密度、克制严谨、高对比度但绝不刺眼的专业终端质感。

### ③ 内部技术与环境细节 (Internal Tech Details)
- **技术栈**：原生 Vue 3 (CDN 全局模式) + 纯 CSS (CSS Variables) + Phosphor Icons。
- **数据通道**：与 `tools/run_product_api.py` 及后端 RESTful API 100% 契约对齐。
- **运行环境**：桌面端主流分辨率 (1920×1080) 与移动端视口 (390×844)。

---

## 2. 红线与硬约束 (Red Lines)

1. **[业务红线]** 严禁破坏现有 API 契约与 Vue 响应式状态流，所有字段保持 100% 兼容。
2. **[合规红线]** 中国竞彩数据已停用前端展示，逻辑代码需完整保留但不在 UI 渲染，严禁恢复竞彩 Tab。
3. **[核心招牌]** Opta AI 胜率分析必须得到视觉强化：在比赛卡片与弹窗中，采用高精度的三色胜率比例条与等宽数字展示，清晰区分主胜（深蓝/青绿）、平局（冷灰/中性色）、客胜（珊瑚红/琥珀金）。
4. **[审美红线]** 坚决摒弃 AI 模板通病：
   - 严禁紫粉渐变背景与霓虹光晕；
   - 严禁大圆角、松垮气泡卡片；
   - 严禁滥用廉价 emoji 图标（统一使用精细线条的 Phosphor Icons）；
   - 严禁空洞的装饰性留白，保证高密度有效数据吞吐。

## 3. 现状诊断 (Audit of Current State)

1. **色彩失衡**：深墨绿顶栏与脏奶油色底纸（`#f5f4ef`）搭配高反差纯白卡片，界面呈现明显的色块切割感，缺乏专业数据终端的统一纵深。
2. **排版失调与严重 Bug**：
   - 移动端下卡片标题 flex 压缩导致“比赛日程表”纵向折行成单列字（“比\n赛\n日\n程\n表”），球队名称出现断折（“切尔\n西”）。
   - 顶部统计卡空间严重浪费，3个大卡片占据首屏大半视口，仅展示3个孤立数字，移动端垂直堆叠挤占比赛首屏。
3. **Opta AI 胜率存在感弱**：原版仅在状态角标下方放置了一条 72px 宽的细线和模糊百分比，主客队色彩归属不明晰，失去核心分析价值。
4. **阵容展现初级**：弹窗首发列表仅为纯文本表格，缺乏球场战术站位与阵型层级感。
